# Bioinformatics Utils (HW4)

Пакеты, разработанные для обработки биоинформатических данных, в частности: фильтрация fastq-файлов,преобразование строк в fasta-файле в одну длинную строку и отбор данных по наилучшим совпадениям. 


## Установка 
Для использования пакетов достаточно склонировать репозиторий: 

```bash
git clone https://github.com/ТВОЙ_НИК/bioinf_utils_hw.git
cd bioinf_utils_hw
```
